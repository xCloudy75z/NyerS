# NyerS — public documentation & method hub

Public documentation for the Neyer (1994) D-optimal sensitivity-test tool,
served via GitHub Pages:

  https://xcloudy75z.github.io/NyerS/

It holds the plain-language method explanation, guides, and background reading —
intended for readers who want to understand *what the method does and why it is valid*.

The tool's **source code is maintained privately** and is intentionally not part of
this repository.
