Using the tool for your drop test

Your setup — drop an object from a chosen height into a hole in a 3D-printed part, and see whether the part breaks — is exactly the problem this method was built for. This page shows how they line up, and how to actually run it.

How your test maps to the method

In your labIn the tool
One fresh 3D-printed partOne test item (used once)
The drop height you set (mm)The "level" — the single dial the tool chooses for you
Part breaks / survivesOutcome you type: 1 = broke, 0 = survived
What you want outAverage breaking height, how much it varies part-to-part, and (optional) the "always breaks" and "always safe" heights
You said you can print as many parts as you want — that is your biggest advantage. The method gets sharper the more parts you spend. With ~10 it's rough and risky; with 20–30+ it becomes reliable. Print generously. This single fact removes the main limitation and is worth telling your instructor.

Step 1 — Find a rough starting height (you said "no idea")

That's fine — the tool self-corrects even from a bad guess. But a rough guess saves parts, so do a quick ladder first (parts are free):

  1. Drop a spare part from a small height (say a few mm). Survived? Go higher.
  2. Roughly double the height each time — e.g. 5, 10, 20, 40, 80 mm — using a fresh part each time, until one breaks.
  3. You now have a rough bracket: the last height that survived and the first that broke. The breaking height lives between them.

Suppose survivors stopped around 40 mm and the first break was around 60 mm. Then your starting guess is: low end 40, high end 60, and a rough spread of maybe 5 mm. (Exact numbers don't matter — the tool refines them.)

Step 2 — Run the real test in MATLAB

Open the tool in MATLAB (see the "How to run in MATLAB" guide), then type — replacing the numbers with your ladder result and the number of parts you'll spend:

params = struct('avg_low', 40, 'avg_high', 60, 'spread_guess', 5);   % your rough guess, in mm
result = run_test(params, 25);   % 25 = how many parts you'll drop
Set the floor so heights never go negative. A drop height can't be below zero, so tell the tool your rig's minimum before you start — usually 0 mm: 
cfg = settings(); cfg.min_level = 0;
result = run_test(params, 25, [], cfg);   % [] keeps it interactive
If the method ever wants a level below your floor it simply tests at the floor and says so — no impossible heights. Full details in the MATLAB guide.

The tool then walks you through it, one part at a time:

Test 1 - set level to 50.0000. Did it break? (1=break / 0=survive):

Set your rig to that height, drop a fresh part, and type 1 if it broke or 0 if it survived. Repeat until it's done. Set the height as close as your rig allows — if your rig only does whole mm, that's fine. If you'd rather the tool only ever suggest whole-millimetre heights, you can change that yourself — see "Settings you can change yourself" in the MATLAB guide. (This only affects the number it prints, never the maths or your results.)

Step 3 — Read your answer

At the end you get, in millimetres:

  • Average breaking height — the height where about half the parts break.
  • Spread — how much the breaking height varies from part to part (your parts' consistency).
  • All-fire height — drop from here and essentially every part breaks.
  • No-fire height — stay below this and essentially none break (a safe height).
  • Each comes with a ± — smaller means more certain. More parts shrink it.
Two honest limits to state up front (and defend):
  • The spread reads slightly low when you use few parts (a known effect that shrinks as you add parts — see the "spread-bias" page). Another reason to print generously.
  • The all-fire / no-fire edges carry a wider ± than the average does — this method measures the whole picture well, but the far edges are inherently less certain. Say that next to those numbers; don't hide it.

Do you benefit? Yes — here's the one-line case

Compared with just dropping parts at evenly-spaced heights, this tool chooses each drop height to learn the most, self-corrects from a bad starting guess, and gives you the spread, not just the average — which is exactly the "better sense of sensitivity" your instructor pointed you to. Spend more parts and every number gets sharper.
