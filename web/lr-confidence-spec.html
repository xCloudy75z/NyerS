Likelihood-Ratio confidence + result visualization — Design Spec

  • Date: 2026-07-01
  • Status: approved in brainstorming (owner, 2026-07-01)
  • Motivation: the owner's instructor points to SenTest (Neyer Software LLC's commercial tool), which reports confidence on the breakpoint via the Likelihood-Ratio (LR) method, and frames acceptance as reliability at a confidence level (e.g. "99.9% break at 95% confidence"). Our tool currently reports only a rough ± (delta method). This adds the accurate LR method, a plain-language detailed report, and a visual normal-distribution chart of the result.
  • Cadence: additive only; two swap-points (#1 shape_model, #6 choose_stage) and the Table 1 acceptance gate stay untouched. Source-tag everything. Base MATLAB/Octave functions only.

1. Decisions settled in brainstorming

  1. Scope: LR confidence on all three — the average, the spread, and the tail levels (all-fire / no-fire).
  2. Bound type: one-sided bounds on the tail levels (the safety-relevant side, matching the spec wording); two-sided intervals on the average and spread.
  3. Confidence dial: adjustable, default 0.95 (industry standard), one tagged constant.
  4. Report: detailed and jargon-free — explains every number in plain words (no bare "95% CI").
  5. Chart: the tool draws a normal-distribution chart of the owner's own result in MATLAB (savable as an image), plus a hub explainer page with an annotated example.

2. The method (plain terms + the maths)

The rough ± assumes symmetric wobble. The Likelihood-Ratio method instead keeps every candidate value that still explains the data almost as well as the best fit, drawing the boundary at a precise statistical threshold. It is more accurate for the spread, for the far tails, and at small samples — and it is what SenTest uses.

Log-likelihood (already used by best_fit): L(mu,sigma) = sum_break ln Phi(z) + sum_survive ln Q(z), z=(x-mu)/sigma. Let Lmax = L(muhat,sigmahat).

Thresholds (from the normal quantile — no toolbox; zc = shape_model(p,'quantile')): - two-sided at confidence C: c2 = shape_model((1+C)/2,'quantile')^2 (C=0.95 → 1.9600² = 3.8415) - one-sided at confidence C: c1 = shape_model(C,'quantile')^2 (C=0.95 → 1.6449² = 2.7055)

Profile-likelihood bounds — a value is inside the interval while 2*(Lmax - Lprofile) <= threshold: - Average (two-sided): profile pμ(m) = max over sigma>0 of L(m,sigma). Find the two m around muhat where 2*(Lmax - pμ(m)) = c2. - Spread (two-sided): profile pσ(s) = max over mu of L(mu,s). Find the two s around sigmahat where 2*(Lmax - pσ(s)) = c2 (keep s>0). - All-fire level (one-sided upper): k = shape_model(tail_fraction,'quantile'), level q=mu+k*sigma. Profile pq(q)=max over sigma>0 of L(q-k*sigma, sigma). Upper bound = the q > qhat where 2*(Lmax - pq(q)) = c1. - No-fire level (one-sided lower): level q=mu-k*sigma; profile pq(q)=max over sigma of L(q+k*sigma,sigma). Lower bound = the q < qhat where 2*(Lmax - pq(q)) = c1.

Solvers (base functions): inner maximisation over sigma uses fminbnd/fminsearch on log sigma (positivity, as best_fit already does). Outer root — expand a bracket outward from the estimate until the LR statistic crosses the threshold (with a sanity cap of a few tested-range widths), then bisect to tolerance.

Graceful failure: if there is no overlap (MLE undefined) all bounds are NaN; if a particular bound cannot be bracketed within the cap, that bound is NaN and the report says "not available" (never a fabricated number).

3. Components (all additive)

3.1 src/math/loglik.m (new shared helper)

The log-likelihood in ONE place (like info_terms holds the info formula): ll = loglik(levels, successes, mu, sigma) — returns L(mu,sigma) with the realmin floor that best_fit uses. best_fit (#2) is refactored to call it (its internal neg_loglik becomes -loglik(...)). Behaviour is identical; the Table 1 gate proves it.

3.2 src/math/lr_confidence.m (new — the engine)

ci = lr_confidence(levels, successes, mu, sigma, cfg) returns a struct: mu_lo, mu_hi, sigma_lo, sigma_hi, all_fire_cbound, no_fire_cbound, confidence_level. Computes the four profile-likelihood bounds above. Uses loglik (#3.1), shape_model inverse for thresholds and k, base optimisers, and the bracket-then-bisect root finder. Returns NaN fields on non-overlap / non-convergence. One job: turn a fitted model + data into LR confidence bounds.

3.3 config/settings.m

s.confidence_level = 0.95;   % RECOMMENDATION (industry/ordnance standard); adjustable dial. addendum LR

Validated in report to be strictly inside (0,1).

3.4 src/workflow/report.m (#9)

After the existing estimate/tail computation, call lr_confidence, store the seven fields on result, and print a detailed, plain-language block (replacing the terse lines). Runs only when overlap exists; the no-overlap early return carries the new fields as NaN. Example output:

=== Neyer sensitivity test: RESULT (25 tests) ===

AVERAGE breaking point: 52.00
  The height where about half the parts break.
  95% confident the true average is between 49.8 and 54.2.

SPREAD (how much parts vary): 4.50
  95% confident the true spread is between 3.4 and 6.1.

ALL-FIRE level (99.9% of parts break): 65.90
  Plan for it to be as high as 69.8 -- we are 95% confident the true
  all-fire level is no higher than that.

NO-FIRE level (99.9% of parts survive): 38.10
  Plan for it to be as low as 34.2 -- we are 95% confident the true
  no-fire level is no lower than that.

(Confidence = how sure we are, given how many parts you tested. More parts
 tighten every range. See the chart: plot_result(result).)

The "99.9%" and "95%" texts derive from cfg.tail_fraction and cfg.confidence_level.

3.5 src/workflow/plot_result.m (new — the chart)

h = plot_result(result, cfg) draws the fitted normal distribution in physical units: - the bell curve pdf(x) = shape_model(x,mu,sigma).phi / sigma over mu ± ~4.5 sigma; - a line at the average, a shaded ±1 spread band; - markers/labels for all-fire and no-fire levels; - the confidence bounds drawn as brackets/shaded margins on the average and the tail levels; - plain-language axis label ("breaking level") and title, and a legend. Returns the figure handle. Optional plot_result(result, cfg, savepath) writes a PNG via print. Standalone (the owner types plot_result(result) after a run; NOT called during the test suite). Uses only base plotting (plot, area/fill, line, text, legend, xlabel, title).

3.6 web/reading-confidence.html (hub explainer)

A new "For you" page: an annotated example bell curve (SVG) showing the average, the spread, the tail levels, and the confidence bounds, with a plain-language explanation of what "confidence" means, why more parts tighten it, and how to read the chart the tool produces. Linked from the hub.

4. Testing

  • tests/test_loglik.m (new): loglik reproduces the exact log-likelihood values best_fit optimised (hand-checked point + agreement with an inline recompute).
  • tests/test_lr_confidence.m (new): on the Table 1 data — every interval contains the MLE; bounds are ordered (lo < est < hi; all-fire upper > estimate; no-fire lower < estimate); an interval widens when confidence rises (0.90 → 0.95 → 0.99); an interval narrows with more data; non-overlap input → all NaN.
  • Independent cross-check: compare our LR bounds against an independent profile-likelihood computation on Table 1, to a sensible tolerance — via a short scipy script (compute the same profile-likelihood intervals from scratch), and additionally against senpy if it exposes the numeric likelihood-ratio bounds (not only plots). scipy is the guaranteed oracle; senpy is a bonus.
  • tests/test_report.m (extend): the seven new fields exist and are ordered on the Table 1 run; the no-overlap case carries them as NaN; the guard rejects confidence_level outside (0,1).
  • tests/test_plot_result.m (new): headless smoke test — figure('visible','off'), call plot_result, and assert a valid figure handle is returned with no error; then attempt print to a temp PNG and assert the file is non-empty if headless PNG export is available in the Octave environment (skip that sub-check with a printed note otherwise). Visual correctness is checked by eye in MATLAB.
  • No regression: full suite + Table 1 acceptance stay green; run_all_tests registers the new tests.

5. Acceptance criteria

  • Table 1 acceptance unchanged (5.3922 / 1.0412, all levels, all running estimates).
  • LR bounds present, plain-language report prints, chart renders in MATLAB and saves a PNG in Octave.
  • LR bounds agree with senpy's likelihood-ratio confidence on Table 1 to tolerance.
  • Full suite green in Octave 11.3.0 and MATLAB R2022b (base functions only).
