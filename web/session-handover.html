1. What Neyen / NyerS is

An in-house MATLAB/Octave implementation of the Neyer (1994) D-optimal sensitivity test — toolbox-free, in C:\Users\games\Documents\Neyen and the public repo xCloudy75z/NyerS.

The problem. Some things can only be tested by destroying them; each test says only broke / didn't — never how close. The method chooses where to test next so each costly one-shot test teaches the most, and from the pattern estimates two numbers: the average breaking point (μ) and the spread (σ). It self-corrects from a badly wrong starting guess.

The method. D-optimal design on a normal model: fit (μ, σ) by maximum likelihood once results overlap, then pick the next level that maximises det(I) = I00·I11 − I01². The sweet spot emerges at ≈1.138σ off-centre (found, never hard-coded). Three stages: find the zone → close the gap → refine.

The owner's real experiment (why this exists). A student runs an impact drop-test on 3D-printed parts for an instructor: drop an object from a chosen height (mm) into a hole in a printed part; it breaks (=1) or survives (=0). Drop height = the stimulus; each part is used once; they can print unlimited parts (advise 20–30+). Rig minimum = 0 mm, and 0 mm never breaks (a guaranteed "survive" anchor); no maximum height. Outputs wanted: average breaking height, spread, and all-fire/no-fire heights, with confidence. The owner likes MATLAB Live Scripts (hence the .mlx bundle, §2.5).

Ground-truth numbers (verified in-tool, the acceptance gate): inputs mu_min=0.6, mu_max=1.4, sigma_guess=0.10, N=20, replaying Neyer's 20 fixed outcomes → μ=5.3922, σ=1.0412. Derived: all-fire (99.9%) point 8.6098, LR upper bound 12.7455; no-fire point 2.1746, LR lower bound ≈ −1.47 (below zero → the tool prints an honest "couldn't pin down — plan for about 73 parts" note instead of the negative number); planner for 0.999 @ 95% recommends 382 parts vs a brute-force 2995; avg 95% LR interval ≈ [4.487, 6.530], spread ≈ [0.537, 2.742].

2.1 The nine core workers (unchanged core; #1 and #6 are SACRED)

  • src/math/shape_model.m — #1, the bell curve (the only place the shape lives). Forward shape_model(x,mu,sigma) → struct .z .phi .Phi .Q .p; inverse shape_model(p,'quantile') = normal quantile (sqrt(2)*erfinv(2p−1)). SACRED swap-point.
  • src/math/best_fit.m — #2, MLE over (μ, log σ); returns [mu,sigma,ll]; calls loglik.
  • src/math/pick_next_level.m — #3, D-optimal picker (fenced grid ±search_window_sigmas·σ, grid_points). Optional side_pref.
  • src/logic/has_overlap.m — #4, Silvapulle condition (min(success levels) < max(failure levels)); gates Stage 2 → Stage 3.
  • src/logic/sanity_clamp.m — #5, clamp wild early fits (μ into tested range, σ ≤ range width).
  • src/logic/choose_stage.m — #6, the three-stage brain. SACRED swap-point.
  • src/workflow/check_inputs.m — #7, reject bad configs — validates the v1.5 user names (avg_low<avg_high, spread_guess>0, integer num_parts≥3); run_test adapts to internal names before choose_stage.
  • src/workflow/run_loop.m — #8, the conductor: per item calls choose_stage, rounds to level_decimals (essential — without it the trajectory drifts off Table 1), applies the min_level floor (v1.3, §2.4), gets the outcome, records. Returns record (now incl. .clamped).
  • src/workflow/report.m — #9, final answer: MLE + Fisher variances (Eqs.5-6), B1 tails, LR bounds, plain-language block. v1.3: reworded to "C% confident that R% break/survive at X mm"; prints an honest "plan for about N parts" note (not a false number) when a bound is degenerate (non-finite, or below zero for no-fire); carries levels/successes on the result struct so reliability_query can use them.

Shared math helpers: loglik.m, info_terms.m, find_root.m (bracket-then-bisect one-sided root), prof_quantile.m (fixed-level profile), pl_opts.m (optimiser options), fit_sigma0.m (positive seed for best_fit). find_root/prof_quantile/pl_opts were lifted out of lr_confidence.m so the v1.3 units reuse them.

2.3 v1.3 — reliability-at-confidence calculator (three numbers, give two get the third)

  • src/math/height_for_reliability.m — Mode A: reliability + confidence → conservative height, either tail. Generalises the all-fire/no-fire bound to any reliability; reuses the LR engine.
  • src/math/reliability_at_height.m — Mode B (the new calc): height + confidence → reliability with a conservative lower bound. Root-finds over the standardised distance k (dual of Mode A). Returns fraction / percent / "1 in N"; floors at 1e-6 with bound_floored. Independently cross-checked against scipy to 6 dp (scripts/crosscheck_mode_b.py).
  • src/math/plan_samples.m — the sample-size planner. Two bases: struct('sigma',s) → Banerjee up-front; struct('n','level','se') → scaled/refined. Floor 20 (with a sourced "why 20" reason: LR asymptotics dependable ~≥20, Silvapulle overlap, estimates still settling). Prints a brute-force "bogey" contrast ceil(ln(1−C)/ln(R)) (2995 for 0.999@95%). GOTCHA: the recommended N is spread-INDEPENDENT (the target scales with σ, so σ cancels) — it depends only on R, C, and plan_rel_precision (0.5). The printed .caveat "depends on the real spread" is a hedge, not literal.
  • src/workflow/reliability_query.m — the wrapper. Interactive menu reliability_query(result) (validated input() loops) and scriptable reliability_query(result, tail, action, value, C) where tail∈{break,survive}, action∈{height_for (value=R), reliability_at (value=x), plan (value=R)}, C defaults to settings().confidence_level. Reliability presets = powers of ten to 1-in-a-million, or free-text %. Reads levels/successes/sigma off result.

2.4 v1.3 — physical floor settings.min_level

Default -Inf (off = pure Neyer, so Table 1 is untouched by construction). Set to 0 for the real rig. Enforced at the run_loop (#8) chokepoint (the single point every stage's chosen level passes through): a below-floor pick is tested at the floor with an honest note; if the floor is off and a pick goes negative, a one-time nudge suggests setting min_level.
