Version log

What each release of the tool added, newest first. Every version passes the same acceptance gate below — new features never change the core answer.

Acceptance gate (unchanged in every version): replaying Neyer's 1994 Table 1 gives average 5.3922, spread 1.0412 (paper 5.39 / 1.04). The full test suite is green in Octave 11.3.0 and MATLAB R2022b.
  1. v1.42026-07-03current

    Plan before you print, and run with pop-ups.

    • Pre-lab planner — plan_prep(params, R, C) tells you, before you print a single part, how many parts to prepare and the first drop height. Also a printable web calculator: before you start.
    • Pop-up test run — run_test_ui() runs a whole test through dialog boxes (settings → a Break/Survive box per drop → the answer + chart), bundled into neyer.mlx as a guided section. No code editing.
    • First full suite pass verified in real MATLAB R2022b (previously only Octave).
  2. v1.3

    Reliability calculator + a physical floor + a single-file bundle.

    • reliability_query(result) — give any two of {height, reliability, confidence}, get the third (Mode A height-for-reliability, Mode B reliability-at-height, plus a sample-size planner).
    • cfg.min_level — an optional rig floor (e.g. 0 mm) so the method never suggests a negative height. Off by default (stays pure Neyer).
    • The whole tool assembled into one file (dist/neyer.m → neyer.mlx).
  3. v1.2

    Confidence bounds + a chart.

    • Likelihood-ratio (profile) confidence intervals — the same method the commercial SenTest tool uses: two-sided for the average and spread, one-sided for the tail levels.
    • plot_result(result) — the fitted bell-curve chart.
  4. v1.1

    The far-tail levels + defensibility hardening.

    • All-fire / no-fire levels (where ~99.9% of parts break / survive), with confidence.
    • Extra verification tests (three optima emerge on their own, spread-guess invariance, grid stability, Banerjee asymptotics) and plain-language notes for defending the method.
  5. v1.0

    The faithful method.

    • Neyer (1994) D-optimal sensitivity test: three stages (find the zone → close the gap → refine), fitting the average and spread by maximum likelihood.
    • Reproduces the paper's Table 1 exactly (5.3922 / 1.0412).

The precise per-version notes also live in VERSION.txt inside the tool download.
