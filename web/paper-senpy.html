senpy — a Python package for sensitivity testing. Implements Neyer's method; open source on GitHub (ACasey13/senpy).

Why it matters to you

The closest free analogue to what you're building — Neyer's method in code — with a roadmap toward adding the 2008 Dror & Steinberg approach. Another useful second opinion, in a different programming language from your MATLAB build.

Think of it as: a second worked-solutions key, in a different language, so agreement between the two gives you real confidence.
How it connects to your drop test: if you want to double-check your tool without R, senpy runs the same Neyer method in Python. Feeding it your drop heights and outcomes and getting the same average / spread would independently confirm your results.
